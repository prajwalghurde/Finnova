# Finnova

Finnova is a modern online investment platform inspired by Zerodha. It allows users to invest in stocks, mutual funds, and derivatives with transparency and ease. The project features three main components:

- **Frontend** – User-facing website built with React and Material UI
- **Backend** – RESTful API for user authentication and investment data
- **Dashboard** – Admin dashboard for managing users and insights



## 🚀 Features

- 📈 Invest in Stocks, Mutual Funds, Derivatives
- 🔐 User Authentication using JWT & bcrypt
- 📊 Charts with Chart.js for performance analysis
- ⚙️ Admin Dashboard to monitor users and data
- 🌐 Real-time data updates
- 📤 Deployed on Render for both frontend and backend




## 🧪 Product Highlight – Flyte
Flyte, a key product of Finnova, offers a seamless and intuitive experience for investment tracking and management.
Flyte is an analytical dashboard designed to help users visualize their investments and interactions using real-time charts and tables. Built using React and Chart.js.

## 📦 Getting Started

1. Clone the repo:
```bash
git clone https://github.com/yourusername/Finnova.git
```

2. Install dependencies:
```bash
cd backend && npm install
cd ../frontend && npm install
cd ../dashboard && npm install
```

3. Setup environment variables in each folder (e.g., `.env`):
```env
# Example for backend
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

4. Run the apps:
```bash
# Run backend
cd backend && npm run dev

# Run frontend
cd ../frontend && npm start

# Run dashboard
cd ../dashboard && npm start
```
